# 🎬 Roblox 3D Story Studio — Autonomous Cloud Render Pipeline

Autonomous 3D Headless Blender render pipeline for viral 9:16 Roblox Story Shorts:
- **18× Parallel Cloud Servers** via GitHub Actions Matrix (`render.yml`)
- **1.3× Pitch-Shifted Narrator Voice + Automatic Silence Cutting + Whisper Word Alignment**
- **44 Studio SFX + Auto-Ducked Background Music (`TEMPOREX - Numbers`)**
- **Bold 1-Word `Montserrat Black` Captions**

## 🚀 How to Render a Video (From Phone or Browser — Close Tab Anytime)

1. Go to the **[Actions tab](../../actions/workflows/render.yml)** (or open the repo in the **GitHub Mobile App**).
2. Tap **Render 3D Roblox Story Video** ➔ **Run workflow**.
3. Enter your project name (e.g. `Video-1`) and select:
   - `final`: Renders the complete 30 FPS `1080×1920` `.mp4` across 18 parallel servers and publishes it straight to **[Releases](../../releases)** for 1-tap download.
   - `preview`: Renders all 53 shot mid-frames in ~90 seconds and generates `qa_preview_sheet.jpg` to verify camera angles.
4. Close your browser or lock your phone — GitHub renders in the background and sends a notification when finished!
